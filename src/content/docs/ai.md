The whole point of Back to Basics is depend on AI less. To learn something new that you would originally vibe-code.

That doesn’t mean that AI is prohibited, but if you AI generate the parts that you are learning, thats a problem. Here’s a few reasons your project might have been returned:

- Extremely AI-generated and unpolished UI
- AI generated code in journals
    - All code in journals should be written by you
- AI generated [README](/docs/readme-guide) or [journals](/docs/fixing-my-project)
